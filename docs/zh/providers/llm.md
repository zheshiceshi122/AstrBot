# 大语言模型提供商

在 WebUI 的「设置」→「模型与 API」→「对话」中点击「新增」，选择模型服务类型。兼容 OpenAI API 的服务可选择 `OpenAI Compatible`，并填写服务商提供的 API Base URL 和 API Key。

填写名称、API Key 和 Base URL 后，在同一张表单中直接填写或选择「模型」，选择「用于聊天的配置文件」，点击「保存并使用」。不必依次打开自定义模型和模型参数弹窗，也不必离开本页选择配置文件。

保留「仅保存模型，暂不切换」可只保存连接和模型。代理、超时等连接设置默认折叠；模型能力、上下文长度和测试按钮保留在下方已配置模型列表。原有「配置文件 → AI → 模型 → 对话模型」入口仍可使用。

详细步骤见 [接入模型服务](./start.md)。

> 提供商连接配置保存在 `data/cmd_config.json` 的 `provider_sources` 字段，具体模型配置保存在 `provider` 字段。
